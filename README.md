# VoiceShield AI

AI-powered voice deepfake detection prototype.

## Problem

AI-generated and cloned voices can be misused for impersonation and fraud.

## Solution

VoiceShield AI analyzes speech audio and estimates whether it is likely genuine or synthetic/manipulated.

## Architecture

Audio Input
↓
Audio Preprocessing
↓
AI Voice Detection
↓
Risk Calculation
↓
Security Dashboard
